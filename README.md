# jev

C#で開発するアプリケーションのリポジトリです。

## 開発環境

プロジェクト作成後に、必要な.NET SDKのバージョンと利用するUIフレームワークを記載します。

## セットアップ

プロジェクト作成後に、ビルドおよび実行手順を記載します。

## 機密情報の取り扱い

- APIキー、パスワード、接続文字列などをGitへコミットしないでください。
- ローカル専用の設定は `appsettings.Local.json` または `.env` に保存してください。
- 共有が必要な設定例は、実際の秘密情報を含めず `.env.example` などとして追加してください。
